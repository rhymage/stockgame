# AdSense setup

The page currently contains two placeholder elements with the class `ad-slot`.
They are displayed on the intro and result screens, outside active gameplay.

## Before applying

1. Connect `stockgame.rhymage.com` and verify HTTPS works.
2. Add a privacy policy and contact or operator information appropriate for the
   intended audience and jurisdiction.
3. Replace the placeholder slots with the AdSense code issued for the site.
4. Add the publisher-specific `ads.txt` file to `public/ads.txt`.
5. Test mobile layout and ensure ads are not mistaken for game controls.

Do not commit an invented publisher ID. Use the exact publisher ID and snippets
provided by the AdSense account.
